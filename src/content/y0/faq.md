## Yakuza 0 มีภาษาไทยไหม

ตัวเกมไม่มีภาษาไทยอย่างเป็นทางการ รายชื่อภาษาที่รองรับบนหน้าร้าน Steam (ตรวจเมื่อกันยายน 2026) ไม่มีภาษาไทย แต่เล่นเป็นภาษาไทยได้ด้วยม็อดแปลไทยที่แฟนเกมทำ แจกฟรีที่ปุ่มดาวน์โหลดด้านบน ม็อดแปลเนื้อเรื่องหลัก ซับสตอรี่ ซับคัตซีน บทสนทนาทั้งชุดเสียงพากย์ญี่ปุ่นและอังกฤษ ชื่อและคำอธิบายไอเทม คำอธิบายสกิล ชื่อศัตรู และเมนูส่วนใหญ่ พร้อมฟอนต์ไทยที่วางสระและวรรณยุกต์ซ้อนบนพยัญชนะ

## ม็อดใช้กับ Yakuza 0 เวอร์ชันไหนได้

ใช้ได้เฉพาะ **Yakuza 0 Director's Cut** เวอร์ชัน Steam เท่านั้น ต้องมีเกมแท้ของตัวเอง เพราะในชุดม็อดไม่มีไฟล์เกมต้นฉบับ และม็อดเป็นไฟล์สำหรับเกมบน PC จึงใช้กับเครื่องคอนโซลอย่าง PlayStation หรือ Xbox ไม่ได้

## ติดตั้งม็อดแปลไทย Yakuza 0 ยังไง

1. ปิดเกมให้สนิท และรอให้ Steam อัปเดตหรือตรวจไฟล์เกมเสร็จก่อน
2. แตกไฟล์ zip (คลิกขวา → Extract All) แล้วเปิดโฟลเดอร์เกมอีกหน้าต่าง: Steam → คลิกขวาที่ Yakuza 0 Director's Cut → Manage → Browse local files จะเห็นโฟลเดอร์ `runtime` อยู่ข้างใน
3. ลากโฟลเดอร์ `runtime` จากชุดม็อดไปวางทับในโฟลเดอร์เกม เมื่อ Windows ถาม ให้ตอบ Merge the folder และ Replace the files in the destination แล้วเปิดเกมได้เลย

## ติดตั้งแล้วเกมยังเป็นภาษาอังกฤษ หรือเปิดเกมไม่ขึ้น

ดูว่ามีไฟล์ `dinput8.dll` อยู่ในโฟลเดอร์เดียวกับ `yakuza0_dc.exe` (คือ `runtime\media\`) หรือไม่ ถ้าไม่มีแปลว่าวางผิดที่ เกมจะเปิดได้ปกติแต่ยังเป็นภาษาอังกฤษ ส่วนกรณีเปิดเกมไม่ขึ้น ให้ย้าย `dinput8.dll` ออกจาก `runtime\media` ชั่วคราวแล้วลองเปิดใหม่ ถ้ายังค้าง ให้กด Verify integrity of game files ใน Steam แล้วแจ้งมาที่[หน้าแจ้งบั๊ก](/report/)

## อัปเดตม็อดเวอร์ชันใหม่ หรือ Steam อัปเดตเกม ต้องทำอะไรบ้าง

ม็อดเวอร์ชันใหม่ลากวางทับของเดิมได้เลย เซฟเดิมใช้ต่อได้ ส่วนเมื่อ Steam อัปเดตเกมหรือกด Verify integrity of game files ไฟล์แปลบางส่วนจะถูกเขียนกลับเป็นต้นฉบับ แค่ลากโฟลเดอร์ `runtime` วางทับใหม่ก็กลับมาเป็นภาษาไทย

## แอนตี้ไวรัสเตือนไฟล์ dinput8.dll อันตรายไหม

`dinput8.dll` ทำหน้าที่จัดวางวรรณยุกต์ไทยตอนเกมรัน ไม่ได้แก้ไฟล์ exe ของเกม แอนตี้ไวรัสบางตัวเตือนไฟล์ลักษณะนี้ทั้งที่ไม่มีอันตราย ให้ตรวจก่อนว่าไฟล์โหลดมาจากปุ่มดาวน์โหลดในหน้านี้ หรือหน้าม็อดบน Nexus Mods ที่เว็บนี้ลิงก์ไว้ แล้วค่อยตั้งยกเว้นเฉพาะไฟล์นั้น อย่าปิดแอนตี้ไวรัสทั้งระบบ

## ถอนม็อดหรือกลับไปเล่นภาษาอังกฤษยังไง

ใน Steam คลิกขวาที่เกม → Properties → Installed Files → Verify integrity of game files แล้วลบ `runtime\media\dinput8.dll` กับ `runtime\media\y0dc_thai.ini` เอง เพราะ Steam ไม่ลบไฟล์ที่ไม่ใช่ของเกมให้
