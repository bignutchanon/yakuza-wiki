ม็อดแปลไทย **Yakuza 6: The Song of Life** ออกเวอร์ชัน **v1.4** แก้ช่องไฟตัวอักษรไทยที่เคยห่างเป็นช่อง ๆ เท่าคันจิให้เป็นแบบสัดส่วนเหมือนฟอนต์ไทยปกติ ติดตั้งทับ v1.3 ได้เลย เซฟเดิมใช้ต่อได้ และตั้งแต่รุ่นนี้ลิงก์ดาวน์โหลดย้ายมาอยู่ที่ GitHub Releases แทน Google Drive

## สิ่งที่เปลี่ยน

**ช่องไฟตัวอักษรไทยเป็นแบบสัดส่วน**

- เดิมเกมจัดตัวอักษรไทยทุกตัวให้กว้างเท่าตัวคันจิ อ่านได้แต่ตัวห่างเป็นช่อง ๆ บางเมนูข้อความล้นขอบหรือทับกัน ตอนนี้แต่ละตัวกินที่ตามความกว้างจริงของตัวอักษร
- ทำผ่านไฟล์ `dinput8.dll` ที่วางข้างไฟล์เกม เกมโหลดเองตอนเปิดและปรับค่าเฉพาะตอนเล่น ไม่แก้ไฟล์เกม ตัวอักษรอังกฤษ ตัวเลข และญี่ปุ่นไม่ถูกแตะ
- ระหว่างเล่นกด **F3** เปิด/ปิดตัวแก้ช่องไฟเทียบดูได้ · **F1 / F2** ปรับช่องไฟแน่น/หลวมทีละ 5% · **F4** คืนค่าเริ่มต้น
- คำแปลส่วนอื่นเหมือน v1.3 ทุกประโยค

**รวมของเดิมทั้งหมด**: v1.1 ข้อความระบบ talk (ตัวเลือกสนทนา / prompt มินิเกม / บาร์สแน็ค / หน้า Memories) · v1.2 แก้เกมเด้งตอนโหลดเซฟที่ค้างบาง checkpoint · v1.3 แก้คัตซีนย่อยบางจุดไม่ทำงาน (ซับสตอรี่ป้ายหินโอโนมิจิ)

## ใครควรอัปเดต

- ใช้ **v1.3** อยู่ → อัปเดตได้ตามสะดวก ถ้าไม่อยากลงใหม่ทั้งชุด ก๊อปแค่ `dinput8.dll` จากซิปไปวางข้าง `Yakuza6.exe` ก็ได้ช่องไฟใหม่แล้ว
- ใช้ **v1.1 / v1.2** อยู่ → **ควรอัปเดต** จะได้ทั้งตัวแก้เกมเด้ง ตัวแก้คัตซีนย่อย และช่องไฟใหม่พร้อมกัน

## วิธีอัปเดต

1. ปิดเกมให้สนิท แล้วโหลด v1.4 จากปุ่มดาวน์โหลดในหน้า [Yakuza 6](/game/y6/)
2. แตกซิปออกมาก่อน แล้วดับเบิลคลิก `ติดตั้ง.bat` — ตัวติดตั้งหาโฟลเดอร์เกมเอง สำรองไฟล์เดิม แล้วประกอบไฟล์รูป UI กับ talk ใช้เวลาสักพัก **อย่าปิดหน้าต่าง** และต้องมีที่ว่างราว 3 GB · Windows ขึ้น "Windows protected your PC" กด More info → Run anyway
3. **ตั้งภาษาเกมใน Steam เป็น Japanese / 日本語** (คลิกขวาเกม → Properties → Language) ถ้าไม่ตั้ง เกมจะไม่ขึ้นภาษาไทย — ในเกมจะไม่มีญี่ปุ่นโผล่ เพราะม็อดเปลี่ยนรูป UI เป็นอังกฤษให้แล้ว
4. เปิดเกมได้เลย — **เซฟเดิมใช้ต่อได้** ไม่ต้องเริ่มใหม่

> ตัวแก้ช่องไฟกับตัวติดตั้งทำงานกับไฟล์เกมโดยตรง โปรแกรมสแกนไวรัสบางตัวอาจเตือน เป็น false positive · ถ้า Steam อัปเดตเกมหรือกด Verify integrity ไฟล์แปลจะหาย ต้องรัน `ติดตั้ง.bat` ใหม่ · อยากปิดเฉพาะตัวแก้ช่องไฟ ลบ `dinput8.dll` ทิ้งอย่างเดียว

> ลิงก์ Google Drive เดิมเลิกใช้แล้ว ต่อไปทุกรุ่นแจกผ่าน GitHub Releases ที่ไม่มีลิมิตดาวน์โหลดรายวัน
