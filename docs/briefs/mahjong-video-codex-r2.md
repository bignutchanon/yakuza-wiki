## 1. ปัญหาที่เห็นจากภาพ (ต้องหายทั้งหมด)

1. **กำแพงหมุนผิดแกน** — กำแพงด้านข้างกลายเป็น "ครีบ" ยาวสีขาว/แดงพาดผ่านมือ (`19-calls`) และกำแพง 4 ด้านยาวเกินจนไขว้กันที่มุม (17 กอง × 1.04 = 17.7 แต่วางที่ ±6.4)
2. **มือเราอยู่หลังกำแพงด้านหน้า** — กำแพงด้านใกล้กล้องกินพื้นที่ล่างจอเกือบครึ่ง (`06-shape`) และมือ 14 ใบล้นเฟรมทั้งซ้ายขวา (เห็นแค่ 12 ใบ)
3. **ไพ่ในมือนอนราบ + ย่อ 0.74** — brief ให้มือ "ตั้งหันหน้าเข้ากล้อง" ขนาดเท่ากำแพง
4. **การกระทำในสตอรี่บอร์ดแทบไม่มีเลย**: ไม่มีจั่ว/ทิ้ง/กองทิ้ง · ไม่มีแยกกลุ่ม/หรี่/แถบทอง (S2) · ไม่มีไพ่สมมติที่รอ · ไม่มีไม้ริอิจิ/ทิ้งขวาง/กรอบล็อก/ป๊อปอัปไพ่ที่รอ (S4) · ไม่มีมือคนอื่น/ป้ายที่นั่ง/ปง/ชี/ชุดเปิด/คัง (S6) · ไม่มีมือล้มหงาย/ลูกศรจ่าย/กากบาท (S7) · ไม่มีไพ่บอกโดระ/ลูกศร/ตัวอย่าง (S8) · ไม่มีป้ายหน้าแถว/เลขใต้ไพ่ตัวอักษร (S1)
5. **ชิปทุกอันอยู่ตำแหน่งตายตัว** (960, 300) — ต้องเกาะตำแหน่งไพ่จริง · คำว่า "ยากุ" (S4) ต้องเป็นตัวใหญ่กลางบนพร้อมบรรทัดคำอธิบาย ไม่ใช่ชิปเล็ก
6. **หัวเรื่องฉากเปิดทับกำแพง** อ่านยาก (`01-intro`) · **เช็กลิสต์ S9 ลอยทับโต๊ะ** ไม่มีพื้นรอง (`30-recap`)
7. **วงทองรอบโต๊ะ (torus) เป็นวงกลมบนโต๊ะสี่เหลี่ยม** ดูแปลก → เปลี่ยนเป็นเส้นขอบทองสี่เหลี่ยมตามขอบโต๊ะ
8. **เวลาแบบ absolute กระจายหลายไฟล์** (`shift(..., 9.85)`, `recapStart = 127.85` ใน overlay, เวลาชิปเขียนตายตัว) — พอฉากหนึ่งยืด ฉากหลังพังหมด

## 2. โครงที่ต้องเปลี่ยน (ทำก่อนแก้ภาพ)

แยก "คำนวณสถานะ" ออกจาก "วาด" — เพื่อให้ตรวจเฟรมด้วย node ได้โดยไม่ต้องเปิด Chrome (§4):

- `src/layout.js` (ไม่มี DOM/WebGL — import `three` ได้เพราะใช้แค่คณิตศาสตร์): ค่าคงที่ผังโต๊ะ + ฟังก์ชันคำนวณตำแหน่ง/การหมุนของไพ่แต่ละใบตามช่องที่อยู่ (`hand`, `pond`, `meld`, `wall`, `free`) ของที่นั่งไหน ลำดับที่เท่าไร
- `src/state.js` (ไม่มี DOM/WebGL): `stateAt(t)` คืนสถานะทั้งเฟรม `{ camera: {pos, look, fov}, tiles: [{id, code, pos, rot, faceUp, opacity, dim, glow}], overlay: { caption, title, chips: [{text, anchor:[x,y,z], kind}], arrows, crosses, panels, recap } }` — ฟังก์ชันบริสุทธิ์ของ t
- `src/timeline.js`: ฉากเก็บ **`duration`** (ไม่ใช่ start/end) — เวลาเริ่มของฉากคำนวณสะสม · เหตุการณ์และคำบรรยายในฉากใช้ **เวลาสัมพัทธ์จากต้นฉาก** (`at: 1.6`) ทั้งหมด · ห้ามมีเลขเวลา absolute ในไฟล์อื่น (overlay/actors ต้องอ่านจาก state)
- `src/actors.js` / `src/overlay.js`: แค่เอา state ไปใส่ three.js object / DOM — ไม่มีตรรกะเวลาเอง
- เหตุการณ์ (event) ที่ต้องรองรับ: `draw` (กำแพง → มือ) · `discard` (มือ → กองทิ้ง, `sideways` ได้) · `call` (กองทิ้งคนอื่น + ไพ่ในมือเรา → ชุดเปิด, ระบุใบขวาง) · `reveal` (มือล้มหงาย) · `gap` (แยกกลุ่ม) · `highlight` (หรี่ใบอื่น + แถบทอง) · `ghost` (ไพ่สมมติโปร่ง) · `chip` · `bigword` · `arrow` (จ่ายแต้ม) · `cross` · `popup` · `stick` · `lock` · `reset` (กลับสถานะตั้งต้นของฉาก) — แต่ละ event มี `at` + `dur` แล้ว interpolate ด้วย easing ระหว่างทาง

## 3. ผังโต๊ะ (ใช้ค่าพวกนี้ ห้ามสเกลไพ่รายกลุ่ม)

- หน่วย = ความกว้างไพ่ · ไพ่ทุกใบสเกล 1.0: กว้าง 1.00 (แกน x ของไพ่) · สูง 1.35 (แกน y ของไพ่) · หนา 0.77 (แกน z ของไพ่) · **หน้าไพ่หันไป +z ของตัวไพ่**
- แกนโลก: y ขึ้น · ที่นั่ง **เรา** อยู่ฝั่ง +z หันหน้าไป −z · **ขวา** = +x · **ตรงข้าม** = −z · **ซ้าย** = −x (มองจากบน ลำดับ เรา → ขวา → ตรงข้าม → ซ้าย วนทวนเข็มนาฬิกาพอดี)
- **ใช้ `Group` ต่อที่นั่ง** หมุนรอบแกน y: เรา 0 · ขวา +π/2 · ตรงข้าม π · ซ้าย −π/2 — ในกรุ๊ปเขียนพิกัดแบบ "ที่นั่งเรา" เสมอ แล้วปล่อยให้การหมุนกรุ๊ปพาไปที่นั่งอื่น (แก้ปัญหากำแพงหมุนผิดแกนทั้งหมด)
- พิกัดในกรุ๊ปที่นั่ง (z = ระยะจากกลางโต๊ะไปทางเจ้าของที่นั่ง):
  - **กำแพง**: 17 กอง ระยะห่าง 1.02 ตามแกน x (กึ่งกลาง ±8.16) · 2 ชั้นนอนคว่ำ (หมุน x = +π/2 → หลังไพ่สีแดงอยู่ด้านบน) ความสูงศูนย์กลางชั้น 0.385 / 1.155 · แนวกึ่งกลางกำแพงที่ z = 9.4 (ไพ่นอนยาวตามแกน z) → 4 ด้านไม่ไขว้กัน
  - **กองทิ้ง**: นอนหงาย (หมุน x = −π/2 → หัวไพ่ชี้เข้ากลางโต๊ะ เจ้าของอ่านได้ตรง) แถวละ 6 ใบ เริ่ม x = −2.55 ไปทาง +x ห่าง 1.02 · แถวแรก z = 3.2 แถวถัดไป +1.40 · ไพ่ทิ้งขวาง = หมุนรอบ y อีก 90°
  - **มือ**: ตั้งตรง หน้าไพ่หัน +z (หาเจ้าของ) ที่ z = 11.6 กึ่งกลางตามจำนวนใบ ระยะห่าง 1.02 · ใบที่เพิ่งจั่วเว้นช่อง 0.35 ทางขวา · ที่นั่งอื่นจะเห็นหลังไพ่สีแดงเองโดยอัตโนมัติ
  - **ชุดเปิด**: นอนหงายบนโต๊ะที่ z = 11.6 ทางขวาของมือ (เริ่มห่างขอบมือ 0.8) ใบที่ขอมาหมุน y 90° (ชีจากซ้าย = ซ้ายสุดของชุด · ปงจากตรงข้าม = กลางชุด)
  - **ไม้ริอิจิ**: นอนที่ z = 7.6 ยาว 3.4 หน้าตัด 0.16 × 0.08 สีขาว จุดแดงกลาง
- โต๊ะ: ผ้าสักหลาดสี่เหลี่ยมครึ่งกว้าง 15 · ขอบดำ · เส้นทองสี่เหลี่ยมที่ครึ่งกว้าง 14.7 · ลบ torus วงกลม

## 4. ตรวจเฟรมด้วย node (ให้ Codex ใช้แทนตาเอง)

เพิ่มใน `check.mjs` (import `three` จาก `./node_modules` + `src/state.js`):

- ทุก `reviewTimes` และทุก 0.5 วิ: ไพ่ที่ state ระบุว่าเป็น "ตัวเอก" ของจังหวะนั้น (ไพ่ที่ถูกพูดถึง/เคลื่อนที่/มือเรา) — project มุมทั้ง 8 ของกล่องไพ่ด้วยกล้องของเฟรมนั้น ต้องอยู่ในขอบปลอดภัย 5% ทุกมุม
- ฉากมือ (S2, S5 และมือใน S3–S4): แถวมือต้องกว้าง 70–90% ของเฟรม · ความสูงไพ่บนจอ ≥ 120 px ที่ 1080p
- ห้ามไพ่ที่เป็นตัวเอกถูกบัง: ยิง ray จากกล้องไปจุดกึ่งกลางหน้าไพ่ตัวเอก ต้องไม่ชนกล่องของไพ่/กำแพงใบอื่นก่อน (ใช้ `Box3` + `Ray.intersectBox` พอ)
- ชิปทุกอันต้องอยู่ในขอบปลอดภัย และไม่ทับกล่องคำบรรยาย (กล่องคำบรรยายถือเป็นสี่เหลี่ยม y ≥ 860 px)
- ฉากที่ไม่ต้องใช้กำแพง/ที่นั่งอื่น (S2, S5) ให้ซ่อนไปเลย — ไม่ต้องหามุมกล้องหลบ
- พิมพ์ตาราง: เวลา · ฉาก · %ความกว้างมือ · ไพ่ตัวเอกที่หลุดขอบ/ถูกบัง

## 5. ลิสต์สิ่งที่ต้องเห็นในภาพตรวจ (ตาม §6 ของ brief หลัก)

ให้ใส่ `reviewTimes` ใหม่ตรงจังหวะเหล่านี้ (เวลาสัมพัทธ์ในฉาก → แปลงเป็น absolute ตอนส่งออก):

- **S0**: หัวเรื่องอยู่บนแถบมืดไล่เฉด (หรือกล้องจัดให้ครึ่งบนว่าง) อ่านชัด ไม่ทับไพ่
- **S1**: 4 แถวกว้าง ~65% ของเฟรม · ป้ายหน้าแถว · เลข 1–9 ใต้แถวตัวอักษร · ป้ายใต้แถว 4 · ชิป "1 ไม้ไผ่ = รูปนก" ชี้ `1s` จริง
- **S2**: มือ H1 ตั้งเต็มเฟรม → แยก 5 กลุ่ม → ชิป "เรียง" เหนือ 3 กลุ่ม (หรี่ที่เหลือ + แถบทอง) → "ตอง" → "คู่" → ทุกกลุ่มสว่าง + ชิปใหญ่ "4 ชุด + 1 คู่ ✓"
- **S3**: มือ 13 ใบ `234m 567p 88p 345s 6s 1z` · `6s` บินจากกำแพงเข้ามือ · `1z` บินลงกองทิ้ง · ไพ่สมมติ `8p`/`6s` โปร่งข้างคู่ + ชิปชี้
- **S4**: "ยากุ" ตัวใหญ่กลางบน · จั่ว `9m` → ทิ้งขวาง + ชิป "ริอิจิ!" · ไม้ริอิจิเลื่อนมาวาง · กรอบล็อกรอบมือ · จั่ว `2p` → ลงกองทิ้งเอง · ป๊อปอัป "ไพ่ที่รอ" (ใช้ภาพหน้าไพ่จริงจาก canvas ที่ประกอบแล้ว)
- **S5**: มือตัวอย่างทีละมือ ตั้งเต็มเฟรม + ชิปชื่อยากุ · ไพ่ธรรมดาล้วน = ติ๊กเล็กบนทุกใบ · ยากุไฮ = เน้น `777z` · เจ็ดคู่ = เน้นทีละคู่
- **S6**: ภาพบนทั้งโต๊ะ: มือ 4 ที่นั่ง (ที่นั่งอื่นเห็นหลังไพ่) · กองทิ้งทุกคนมีไม่กี่ใบ · ชิปที่นั่ง 4 อัน · ลูกศรลำดับเล่น · ปง `7z` จากตรงข้าม → ชุดเปิด (ใบขวางกลาง) → ทิ้ง `1z` · ชี `5p` จากซ้าย → ชุดเปิด (ใบขวางซ้ายสุด) → ทิ้ง `3z` · ภาพประกอบคัง `8888s` · ไม้ริอิจิ + กากบาท
- **S7**: มือริอิจิ + ไม้ + `9m` ขวางในกองทิ้ง · จั่ว `8p` เรือง → มือล้มหงาย + "สึโม!" + ลูกศร 3 เส้น · reset → ตรงข้ามทิ้ง `6s` + "รอน!" + ลูกศรเส้นเดียว · reset → `6s` ในกองทิ้งเราเรืองแดง + ซ้ายทิ้ง `8p` + ชิป "รอน" มีกากบาท
- **S8**: ไพ่บอกโดระ `3p` หงายบนกำแพง · ลูกศร → `4p` โปร่ง + ชิป "โดระ" · แผงตัวอย่าง 3 คู่ (ภาพไพ่จริง + ลูกศร)
- **S9**: แผงเช็กลิสต์ครึ่งซ้ายมีพื้นทึบแบบกล่องคำบรรยาย · โต๊ะอยู่ครึ่งขวา · บรรทัดท้ายในแผง: **"ไกด์เต็ม + คำศัพท์ → yakuzathai.com/mahjong/"** (เปลี่ยนจาก "ศัพท์บนจอเกม") · ฉากยาว ≥ 8 วิ
