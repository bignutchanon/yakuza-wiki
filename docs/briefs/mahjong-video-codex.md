## 4. เครื่องมือเรนเดอร์ — สเปก

### 4.1 หลักการ

- `window.renderAt(t)` (t = วินาที) ต้องเป็น**ฟังก์ชันบริสุทธิ์ของ t**: ตั้งทุกอย่าง (ไพ่ กล้อง แสง overlay) จากข้อมูลใน `timeline.js` แล้ว `renderer.render()` แบบ synchronous — เรียก t เดิมกี่ครั้งก็ต้องได้ภาพเดิมทุกพิกเซล ไม่ขึ้นกับเฟรมก่อนหน้า
  - แนวที่แนะนำ: แต่ละฉากมีฟังก์ชัน `setup()` วางสถานะตั้งต้นของไพ่ทุกใบ + รายการ tween `{ actor, prop, t0, t1, from, to, ease }` → `renderAt(t)` หาฉากที่ t อยู่ รีเซ็ตเป็นสถานะตั้งต้นของฉากนั้น แล้วไล่ใส่ tween ที่ `t0 <= t` ตามลำดับเวลา
- ห้ามใช้ `Date.now` · `performance.now` · `Math.random` (ต้องสุ่มให้ใช้ PRNG มี seed คงที่ เช่น mulberry32) · ห้าม CSS `transition` / `animation` / `@keyframes` ใน overlay (ตั้ง style ตรง ๆ ทุกเฟรม) — `check.mjs` จะค้นหาคำพวกนี้
- เวทีขนาด 1920×1080 CSS px ตายตัว · `renderer.setPixelRatio(1)` · ไม่มี bundler ใช้ ES modules + import map:
  ```html
  <script type="importmap">{"imports":{"three":"./node_modules/three/build/three.module.js","three/addons/":"./node_modules/three/examples/jsm/"}}</script>
  ```
- โหมดผ่าน query string: `?t=12.5` = วาดเฟรมเดียว (ไว้ตรวจ) · `?play` = เล่นตามเวลาจริงพร้อมแถบเลื่อนเวลา (ไว้ดูตอนพัฒนา) · ไม่มี query = รอ `render.mjs` สั่ง (ไม่มี UI ส่วนเกินบนเวที)
- `window.ready` = Promise ที่ resolve หลังฟอนต์โหลดครบ (`document.fonts.load()` ทุกน้ำหนักที่ใช้ แล้วรอ `document.fonts.ready`) และเท็กซ์เจอร์หน้าไพ่สร้างเสร็จ
- `window.timelineInfo` = `{ duration, fps: 30, posterTime, reviewTimes: [...] }`

### 4.2 three.js

- `new WebGLRenderer({ canvas, antialias: true, preserveDrawingBuffer: true })` · `outputColorSpace = SRGBColorSpace` · `toneMapping = ACESFilmicToneMapping` (exposure ราว 1.0) · เงา `PCFSoftShadowMap` ขนาด 2048
- ผิวไพ่ให้มีแสงสะท้อนนุ่ม ๆ: `RoomEnvironment` + `PMREMGenerator` ความแรงต่ำ (ไพ่ควรดูเป็นพลาสติกมันวาว ไม่ใช่กระดาษ)
- ไพ่: สัดส่วนไพ่ริอิจิจริง กว้าง:สูง:หนา ≈ 26:35:20 มม. → หน่วยฉาก 1.00 : 1.35 : 0.77 · ใช้ `RoundedBoxGeometry` (`three/addons/geometries/RoundedBoxGeometry.js`) สองชั้นติดกัน: ชั้นหน้าสีงาช้างหนา ~2/3 + ชั้นหลังสีแดงเข้ม ~1/3 · หน้าไพ่เป็น plane บางแปะหน้าชั้นหน้า (เว้นขอบ ~7%) ใช้เท็กซ์เจอร์จาก §5.3
- ใช้ geometry/material ร่วมกัน — ไพ่ทั้ง 136 ใบใช้ geometry ชุดเดียว ต่างกันแค่เท็กซ์เจอร์หน้าไพ่ 34 แบบ
- กล้อง: `PerspectiveCamera` fov 30–40 · เคลื่อนแบบโดรน เลื่อนนุ่มระหว่างคีย์เฟรมด้วย easeInOutCubic เท่านั้น — **ห้ามสั่น ห้ามโยก/bob ห้ามหมุนวนรอบโต๊ะ ห้ามซูมกระตุก** (เจ้าของเว็บสั่งเรื่องนี้ชัดเจนตอนทำ hero) · เปลี่ยนมุมระหว่างฉากใช้เวลา 0.8–1.2 วิ · ในฉากเดียวกันขยับช้า ๆ ได้ไม่เกิน ~3% ของระยะ
- จัดเฟรมด้วยการคำนวณ ไม่ใช่เดาเลข: ระยะกล้องที่ทำให้เห็นความกว้าง W พอดีเฟรม = `W / (2 · tan(fov/2) · aspect)` · แถวมือ 14 ใบ (~16 หน่วยรวมช่องว่างระหว่างชุด) ควรกว้างราว 85% ของเฟรม

### 4.3 Overlay — DOM ทับ canvas

- **คำบรรยายล่างจอ**: กล่องกึ่งกลาง ห่างขอบล่าง ~70 px · `max-width: 1560px` · พื้น `rgba(13,10,18,0.82)` · แถบแดง 8 px ด้านซ้าย `#e63950` · มุมโค้ง 10 px · padding 22 px / 36 px · Kanit 600 **58 px** line-height 1.5 สี `#ece7dd` · คำที่ timeline เขียนเป็น `**คำ**` = สีทอง `#d4a24e` · ไม่เกิน 2 บรรทัด · `text-wrap: balance` · ปล่อยให้ Chrome ตัดคำไทยเอง (ห้าม `word-break: break-all`)
- **ชิปป้าย** บนกลุ่มไพ่ (เช่น "เรียง" "ตอง" "คู่" "ปง!"): Kanit 700 40 px ตัวขาวบนพื้น `#a31226` มุมมน · ตำแหน่งได้จากการ project จุด 3D ของกลุ่มไพ่ลงจอทุกเฟรม (`vector.project(camera)` → พิกัด px)
- **หัวเรื่อง** (ฉากเปิด): Kanit 800 Italic ~120 px + บรรทัดรอง Kanit 600 ~56 px สีทอง
- **ลายน้ำมุมซ้ายบน** ตลอดคลิป: `yakuzathai.com` Kanit 600 28 px ทึบ 60%
- ขอบปลอดภัย 5% ทุกด้าน · ทุกจุดที่มีตัวหนังสือไทย line-height ≥ 1.4 กันสระบน/วรรณยุกต์/สระล่างโดนตัด
- คำบรรยายเข้า/ออกด้วยการเฟด 0.25 วิ (คำนวณ opacity จาก t)
- คนส่วนใหญ่จะดูบนมือถือในหน้าเว็บกว้าง ~360 px (วิดีโอย่อเหลือ ~19%) → **ห้ามมีตัวหนังสือในวิดีโอเล็กกว่า 36 px** ที่ 1080p

### 4.5 `render.mjs`

- เรียก `startServer()` จาก `serve.mjs` ในโปรเซสเดียวกัน (หาพอร์ตว่างเอง) → puppeteer-core:
  ```js
  launch({ executablePath: 'C:/Program Files/Google/Chrome/Application/chrome.exe', headless: true,
           args: ['--hide-scrollbars', '--force-device-scale-factor=1', '--window-size=1920,1080',
                  '--use-angle=d3d11', '--ignore-gpu-blocklist', '--enable-unsafe-swiftshader'] })
  ```
  viewport 1920×1080 deviceScaleFactor 1 · ถ้า WebGL สร้าง context ไม่ได้ให้ error ชัด ๆ ว่าเพราะอะไร
  (Claude ทดสอบชุด launch นี้นอก sandbox แล้ว 14 ต.ค.: ได้ WebGL2 บน GPU จริง `ANGLE (NVIDIA RTX 3080 Ti, D3D11)` · screenshot 1080p ~165 ms/เฟรม → คลิป ~132 วิ ใช้เวลาจับเฟรมราว 11–15 นาที)
- ต่อเฟรม i: `await page.evaluate(t => window.renderAt(t), i / 30)` → รอ 2 rAF → `page.screenshot({ type: 'png', clip: { x: 0, y: 0, width: 1920, height: 1080 }, optimizeForSpeed: true })` → เขียน Buffer ลง stdin ของ ffmpeg (เคารพ backpressure ด้วย `drain`)
- ขั้นตอนปกติ `node render.mjs`:
  1. จับทุกเฟรม → `out/master.mp4` (`-f image2pipe -framerate 30 -c:v png -i - -c:v libx264 -preset veryfast -crf 12 -pix_fmt yuv420p`) — ไฟล์กลางคุณภาพสูง ไว้เข้ารหัสซ้ำโดยไม่ต้องจับเฟรมใหม่
  2. เข้ารหัสตัวจริงจาก master: `-c:v libx264 -preset slow -tune animation -crf <N> -pix_fmt yuv420p -profile:v high -level:v 4.1 -movflags +faststart -an` → เริ่ม N = 23 ถ้าไฟล์เกิน 8 MB ให้เพิ่ม N ทีละ 1 แล้วลองใหม่ (เพดาน 30 — ถ้ายังเกินให้หยุดแล้วรายงานขนาดที่ได้)
  3. poster: เฟรมที่ `posterTime` จาก master → `scale=1280:720:flags=lanczos` → `-c:v libwebp -quality 82` ถ้าเกิน 150 KB ลด quality ทีละ 5
  4. manifest (§4.6) จาก `ffprobe -v error -print_format json -show_format -show_streams`
  5. หน้าไพ่ 34 ใบ: `window.exportTileFaces()` คืน dataURL `image/webp` ขนาด 72×96 (สองเท่าของขนาดที่แสดง 36×48) → เขียนเป็น `public/mahjong/tiles/<code>.webp`
  6. ภาพตรวจงาน: เฟรมที่ `reviewTimes` → `out/stills/NN-<sceneId>-<t>.png` + `out/contact.png` (ffmpeg filter `scale=480:-1,tile=4x<แถว>`)
- แฟล็ก: `--stills` (ทำแค่ข้อ 6 — เร็ว ไว้ส่งตรวจ) · `--from <วิ> --to <วิ>` · `--scale 0.5` (ฉบับร่าง 960×540 ผ่าน `clip.scale`) · `--encode-only` (ข้ามข้อ 1 ใช้ master เดิม) · `--tiles` (ทำแค่ข้อ 5)

## 6. Storyboard

โค้ดไพ่ใช้แบบ Tenhou: `m` = ตัวอักษร (萬子) · `p` = วงกลม (筒子) · `s` = ไม้ไผ่ (索子) · `1z`–`7z` = 東 南 西 北 白 發 中 (ลมตะวันออก · ใต้ · ตะวันตก · เหนือ · มังกรขาว · เขียว · แดง) · `234m` = 2m 3m 4m

ที่นั่ง (มองจากด้านบน): **เรา** = ด้านล่างใกล้กล้อง · **ขวา** · **ตรงข้าม** · **ซ้าย** — เล่นวนทวนเข็มนาฬิกา (เรา → ขวา → ตรงข้าม → ซ้าย → เรา) คนทางซ้ายจึงเล่นก่อนเราพอดี

ผังโต๊ะ (หน่วย = ความกว้างไพ่ 1 ใบ): กำแพง 4 ด้าน ด้านละ 17 กอง × 2 ชั้น ล้อมเป็นสี่เหลี่ยมกลางโต๊ะ · กองทิ้งของแต่ละคนอยู่ด้านในกำแพงหน้าเจ้าของ แถวละ 6 ใบ · มือของแต่ละคนอยู่นอกกำแพง ตั้งหันหน้าเข้าหาเจ้าของ (เราเห็นหน้าไพ่ของเรา เห็นแต่หลังไพ่คนอื่น) · ชุดเปิด (ปง/ชี/คัง) วางหงายราบทางขวาของมือเจ้าของ — ระยะปรับได้ตามเฟรมจริง

**เวลาข้างล่างเป็นแผน** ยืด/หดได้ถ้า `check.mjs` ฟ้องว่าเวลาอ่านไม่พอ (รวมทั้งคลิปไม่เกิน 150 วิ — แก้จาก 135 ในรอบ 2) แต่**ห้ามแก้ถ้อยคำในคำบรรยาย** — ถ้าเห็นว่าคำไหนผิดหรือยาวเกิน ให้เสนอในรายงาน

### 7.1 `src/lib/content.ts`

`loadAll()` ถือว่าทุกโฟลเดอร์ใน `src/content/` เป็นไอดีเกม ยกเว้น `news` / `lore` ที่มีสาขาของตัวเอง → เพิ่มสาขา `guides` แบบเดียวกับ `lore` (ไฟล์ละบทความ, frontmatter `title` + `date` (ISO)) แล้ว `continue` · export `interface GuideArticle { slug, title, date, body, excerpt }` + `guideBySlug(slug)` · `excerpt` ใช้ `firstParagraph(body)` เหมือนบทความอื่น

### 7.2 `src/app/mahjong/page.tsx` (server component — ไม่มี `'use client'`)

- โหลด `guideBySlug('mahjong')` ถ้าไม่มีให้ `throw new Error(...)` ตอน build (ห้ามปล่อยหน้าเปล่า) · อ่าน manifest ด้วย `import VIDEO from '@/data/videos/mahjong-basics.json'`

- JSON-LD ผ่าน `<JsonLd data={[...]} />`: `articleJsonLd({ headline, description, path, image: VIDEO.poster, datePublished: guide.date, section: 'ไกด์มินิเกม' })` + `breadcrumbJsonLd([{ name: 'วิธีเล่นมาจอง', path: '/mahjong/' }])` + `videoObjectJsonLd(...)` (§7.3)

### 7.3 `videoObjectJsonLd()` ใน `src/lib/seo.ts`

รับ `{ name, description, path, contentUrl, thumbnailUrl, uploadDate, duration }` (`uploadDate` = `YYYY-MM-DD`, `duration` = วินาที) คืนโหนด:

- `@type: 'VideoObject'` · `name` · `description: clip(description)` · `thumbnailUrl: [absUrl(thumbnailUrl)]` · `uploadDate: '<date>T00:00:00+07:00'` · `duration` แบบ ISO 8601 (126 วิ → `PT2M6S`) · `contentUrl: absUrl(contentUrl)` · `inLanguage: 'th-TH'` · `publisher: { '@id': ORG_ID }` · `author: { '@id': PERSON_ID }`
- เขียนตามแบบฟังก์ชันอื่นในไฟล์ (คอมเมนต์ไทยบอกว่าเอาไว้ทำอะไร)
